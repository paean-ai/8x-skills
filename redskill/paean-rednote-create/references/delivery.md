## 本技能的 Red Skill 上架素材

这部分供发行维护者使用，不是普通创作任务必做步骤。上传与发布仍依据当前用户授权执行。

- **标识**：`paean-rednote-create`（最终是否可用以平台为准）。
- **建议名称**：8x 小红书创作工坊。
- **简介草稿**：用想法或已有 HTML 作品制作中文小游戏与互动小工具，生成小红书离线包，按需录制演示并适配 8x 平台。技能在你自己的 AI Agent 中执行。
- **来源**：自有原创入口及 8x MIT 开源工作流，保留完整 LICENSE；维护者应确认代码和素材的实际权属后选择平台的原创/转载选项。
- **使用条件**：具备文件读写和命令执行能力的 Agent；Node.js 18+，Paean TTS 需 20+；转换需 esbuild，验收/录制需 Playwright 与 Chromium，MP4/GIF/海报导出和配音变速需 ffmpeg。用户自己的模型、素材生成或云服务可能产生费用。
- **外部服务披露**：默认创作/转换无需 Paean 账号；选择 8x 发布或 remix 时会连接 `api.paean.ai`，按相应功能上传作品文件/元数据或读取上游作品。选择 Paean TTS 配音时会将文案发送到 Paean 及其上游语音服务，可能产生平台用量。上述本地脚本使用自己的 Paean JWT 鉴权，无需上游 API key；凭据不进入作品或技能发行包。不会提供小红书账号操作权限。
- **边界**：不抓取笔记、不自动运营账号、不保证审核结果；小红书离线版不提供远程 AI、联网对战或云端账号功能。

根 `SKILL.md`、脚本、参考文件及许可必须一起上传。不要上传仓库根、`.git`、项目凭证、`node_modules` 或作品素材目录。发行 ZIP 与文件夹由仓库构建器生成；不能只拖一个 `SKILL.md`。
